# 機能仕様書: Todo統計表示

機能名: `2-todo-stats`  
作成日: 2025-11-23  
モデル名: Claude Sonnet 4.5  
仕様書テンプレートバージョン: 1.0.1

## 概要

Todo一覧の見出し横に完了数と全体数を表示する機能を追加します。

## 要件 *(必須)*

### 機能実装前後の変更点
#### 機能実装前
- 「Todo一覧」という見出しのみが表示される
- 完了数や全体数の統計情報は表示されない

#### 機能実装後
- 「Todo一覧」という見出しの横（同じ行）に「完了: X件 / 全体: Y件」という統計情報が表示される
- 完了数は`completed: true`のTodoの数を表示する
- 全体数は全てのTodoの数を表示する
- Todoの作成・削除・完了状態変更時に自動的に統計情報が更新される

### 機能要件

- FR-001: システムはTodo一覧の見出し横に完了数を表示しなければならない (implement_set_1)_1
- FR-002: システムはTodo一覧の見出し横に全体数を表示しなければならない (implement_set_1)_1
- FR-003: システムはTodoの状態変更時に統計情報を自動的に更新しなければならない (implement_set_1)_1

### エンティティ構造

エンティティ構造の変更は不要です。既存のTodoエンティティを使用します。

## 成功基準 *(必須)*

- 「Todo一覧」見出しの横に「完了: X件 / 全体: Y件」が表示される
- 完了数は`completed: true`のTodoの数と一致する
- 全体数は全てのTodoの数と一致する
- Todoを作成すると全体数が増加する
- Todoを削除すると全体数が減少する
- Todoの完了状態を切り替えると完了数が更新される
- Todoが0件の場合でも「完了: 0件 / 全体: 0件」が正しく表示される

### 型定義 *(新規型が必要な場合に含める)*

新規型定義は不要です。既存の`Todo`型を使用します。

### 実装手順

#### 実装セット implement_set_1: UI実装

- 対象ファイル:
  - `src/routes/+page.svelte` (修正)
- 実装内容: 「Todo一覧」見出しの横に完了数と全体数を表示します。クライアント側で`todos`配列から完了数と全体数を計算します。
- 影響ページ:
  - `/`: Todo一覧セクションに統計情報を追加
- 手順:
  - [x] UI実装(src/routes/+page.svelte)
    - `todos`配列から完了数を計算する変数を追加
      - `completedCount = todos.filter(todo => todo.completed).length`
    - `todos`配列から全体数を計算する変数を追加
      - `totalCount = todos.length`
    - 「Todo一覧」見出しの横に統計情報を表示
      - 見出しと統計情報を同じ行に配置（flexboxを使用）
      - 「完了: {completedCount}件 / 全体: {totalCount}件」の形式で表示
      - スタイリングは既存のデザインに合わせる
  - [x] 動作確認: サーバーを起動し、統計情報が正しく表示・更新されることを確認
    - Todoが0件の場合の表示を確認
    - Todoを作成して全体数が増加することを確認
    - Todoを削除して全体数が減少することを確認
    - Todoの完了状態を切り替えて完了数が更新されることを確認

#### ローカル確認できる項目

- **統計情報の表示**: 
  確認すべき理由: 統計情報が正しく表示されることを確認するため
  確認すべき内容: 「Todo一覧」見出しの横に「完了: X件 / 全体: Y件」が表示されること
  確認方法: ブラウザで`http://localhost:5007/`にアクセスし、ログイン後、Todo一覧セクションを確認する

- **完了数の正確性**: 
  確認すべき理由: 完了数が正しく計算されることを確認するため
  確認すべき内容: 完了数が`completed: true`のTodoの数と一致すること
  確認方法: Todoを作成し、いくつかを完了状態にして、完了数が正しく表示されることを確認する

- **全体数の正確性**: 
  確認すべき理由: 全体数が正しく計算されることを確認するため
  確認すべき内容: 全体数が全てのTodoの数と一致すること
  確認方法: Todoを作成・削除して、全体数が正しく更新されることを確認する

- **統計情報の自動更新**: 
  確認すべき理由: Todoの状態変更時に統計情報が自動的に更新されることを確認するため
  確認すべき内容: Todoの作成・削除・完了状態変更時に統計情報が即座に更新されること
  確認方法: Todoを作成・削除・完了状態を切り替えて、統計情報が自動的に更新されることを確認する

- **0件の場合の表示**: 
  確認すべき理由: Todoが0件の場合でも統計情報が正しく表示されることを確認するため
  確認すべき内容: 「完了: 0件 / 全体: 0件」が表示されること
  確認方法: 全てのTodoを削除して、統計情報が「完了: 0件 / 全体: 0件」と表示されることを確認する
