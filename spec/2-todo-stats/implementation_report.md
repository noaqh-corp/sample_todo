実装結果レポートテンプレートバージョン: 1.0.1

## 概要

Todo一覧の見出し横に完了数と全体数を表示する機能を実装しました。クライアント側で`todos`配列から統計情報を計算し、見出しの横に表示します。

## 実装内容の詳細

### 実装セット1: UI実装
- `src/routes/+page.svelte`を修正し、Todo一覧の見出し横に統計情報を追加
- `todos`配列から完了数を計算する変数`completedCount`を追加
  - `const completedCount = $derived(todos.filter(todo => todo.completed).length);`
- `todos`配列から全体数を計算する変数`totalCount`を追加
  - `const totalCount = $derived(todos.length);`
- 「Todo一覧」見出しの横に統計情報を表示
  - `flex items-center justify-between`を使用して見出しと統計情報を同じ行に配置
  - 「完了: {completedCount}件 / 全体: {totalCount}件」の形式で表示
  - 既存のデザインに合わせたスタイリング（`text-sm text-gray-600 dark:text-gray-400`）
